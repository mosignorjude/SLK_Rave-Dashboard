## Deployment command

Deployment to the verified production project completed on 2026-09-28 after explicit owner approval. Hosting and Firestore Rules recover differently: Firebase Hosting supports a console rollback to a prior live version; Firestore Rules releases cannot be rolled back with Firebase CLI. Rules recovery requires deploying a known-good source file or using the Console ruleset history to restore/clone a prior ruleset. Keep a known-good local `firestore.rules` and Hosting release history available.

```sh
npm run build
npx firebase-tools deploy --only firestore:rules,hosting --project slk-rave-db
```
